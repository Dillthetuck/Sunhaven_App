# Sunhaven portfolio care prototype

A dependency-free, fictional-data prototype for exploring Sunhaven’s assisted insurance document collection and portfolio review experience.

## Open the prototype

Open `index.html` in a browser. No install or build step is required. Use the switch in the top right to move between the staff workspace and investor experience.

## What’s included

- Staff work queue and account workspace with overview, collection, documents, review, and activity sections.
- Investor overview, portfolio confirmation, collection method, agent contact, illustrative authorization, collection progress, review summary, and property-change report.
- Interactive demo controls with explicit simulated-action messaging.
- Fictional people, entities, properties, carrier names, documents, and findings only.

## Prototype limits

This is a front-end design prototype. It does not authenticate users, store or upload files, contact agents, collect signatures, send messages, or change insurance. A demo role switch is not an access control. Authorization screens are illustrative, and findings are not insurance advice. Published findings are distinguished from internal drafts; missing documents are treated as unknown information, not a confirmed coverage gap.
